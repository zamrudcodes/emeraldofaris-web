# Emeraldo Faris 

The personal portfolio website of Emeraldo Faris Aufar, a digital marketer and aspiring software engineer.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features

- **About Me**: Brief introduction and professional background.
- **Live Age**: A component displaying my current age in real-time.
- **Projects**: Showcase of my work including Marka, Bakso Tujuh Pemuda and other projects.
- **Social Links**: Connect with me on X, Email GitHub, LinkedIn, and Instagram.
